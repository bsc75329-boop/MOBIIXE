# 하드웨어 구성도

## 필요 부품

| 부품 | 수량 | 설명 |
|------|------|------|
| Arduino Uno (또는 호환 보드) | 1 | 메인 컨트롤러 |
| L298N 모터 드라이버 모듈 | 1 | DC 모터 2개 제어 가능 |
| DC 모터 (3~6V) | 2 | 왼쪽/오른쪽 구동 모터 |
| 외부 전원 (7~12V 배터리) | 1 | 모터 구동용 전원 |
| 점퍼 와이어 | 약 10개 | 배선용 |
| USB 케이블 | 1 | 아두이노 프로그래밍 및 시리얼 통신 |

## 배선도 (L298N ↔ Arduino Uno)

```
  ┌─────────────────────────────────────────────┐
  │              외부 전원 (7~12V)                │
  │              + ────── -                      │
  └──────┬──────────────┬───────────────────────┘
         │              │
   ┌─────┴──────────────┴─────────────────┐
   │           L298N 모터 드라이버          │
   │                                       │
   │  +12V ◄── 외부전원 (+)                │
   │  GND  ◄── 외부전원 (-) + Arduino GND  │
   │  +5V  ──► (점퍼 연결 시 아두이노 전원) │
   │                                       │
   │  ENA  ◄── Arduino D5 (PWM)            │
   │  IN1  ◄── Arduino D7                  │
   │  IN2  ◄── Arduino D8                  │
   │  IN3  ◄── Arduino D9                  │
   │  IN4  ◄── Arduino D10                 │
   │  ENB  ◄── Arduino D6 (PWM)            │
   │                                       │
   │  OUT1 ──► 모터A (+)                   │
   │  OUT2 ──► 모터A (-)                   │
   │  OUT3 ──► 모터B (+)                   │
   │  OUT4 ──► 모터B (-)                   │
   └───────────────────────────────────────┘
```

## 핀 연결 상세표

### Arduino → L298N

| Arduino 핀 | L298N 핀 | 역할 |
|------------|----------|------|
| D5 (PWM)   | ENA      | 모터A 속도 제어 |
| D6 (PWM)   | ENB      | 모터B 속도 제어 |
| D7         | IN1      | 모터A 방향 제어 |
| D8         | IN2      | 모터A 방향 제어 |
| D9         | IN3      | 모터B 방향 제어 |
| D10        | IN4      | 모터B 방향 제어 |
| GND        | GND      | 공통 접지 |

### L298N → 모터

| L298N 핀 | 연결 대상 |
|----------|----------|
| OUT1     | 모터A (+) |
| OUT2     | 모터A (-) |
| OUT3     | 모터B (+) |
| OUT4     | 모터B (-) |

## 전원 구성

```
외부 배터리 (7~12V)
  ├── (+) ──► L298N +12V 단자
  └── (-) ──► L298N GND 단자 ──► Arduino GND (공통 접지 필수!)

Arduino USB 전원
  └── 아두이노 로직 전원 (5V)
```

### 전원 관련 주의사항

1. **공통 접지 (GND) 필수**: Arduino GND와 L298N GND를 반드시 연결
2. **외부 전원 전압**: 7~12V 권장 (모터 사양에 맞게 조절)
3. **L298N 5V 점퍼**: 12V 이하 입력 시 점퍼를 꽂으면 5V 출력으로 아두이노에 전원 공급 가능
4. **전류 용량**: 모터 소비 전류를 고려하여 배터리 선택 (모터당 약 0.5~1A)

## 모터 동작 원리

| IN1 | IN2 | 모터A 동작 |
|-----|-----|-----------|
| HIGH | LOW | 정방향 회전 |
| LOW | HIGH | 역방향 회전 |
| LOW | LOW | 정지 |
| HIGH | HIGH | 브레이크 |

> 모터B도 IN3/IN4로 동일한 방식으로 동작합니다.

## 시리얼 명령어

| 키 | 동작 |
|----|------|
| W  | 전진 |
| S  | 후진 |
| A  | 좌회전 |
| D  | 우회전 |
| X  | 정지 |
| 1~9 | 속도 조절 (1=느림, 9=빠름) |
