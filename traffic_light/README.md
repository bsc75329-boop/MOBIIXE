# ESP32-C3 횡단보도 신호등 제어

`traffic_light.ino` 하나로 동작합니다.

## 기능
| 기능 | 동작 |
|---|---|
| 자동 (전원 ON 시 기본) | 빨간불 5초 → 초록불 5초 → 무한 반복 |
| 수동 | 명령으로 빨간불/초록불과 유지 시간 지정. 한쪽이 켜지면 다른 쪽은 자동 OFF |
| 상태 표시 | 1초마다 켜진 불 왼쪽에 `▶` 화살표, 남은 시간 / 유지 시간 표시 |

```
[수동] -----------------------------
▶ 빨간불  ON   남은 7초 / 유지 10초
  초록불  OFF
```

## 명령어
| 입력 | 의미 |
|---|---|
| `R 10` | 빨간불 10초 ON (소수 가능: `R 2.5`) |
| `G 7` | 초록불 7초 ON |
| `R` / `G` | 시간 생략 시 계속 ON |
| `OFF` | 모두 OFF |
| `AUTO` | 자동 모드로 복귀 |
| `STATUS` | 현재 상태 |
| `HELP` | 명령어 목록 |

수동 유지 시간이 끝나면 모두 OFF 상태로 기다립니다. `AUTO`를 입력하면 자동 반복으로 돌아갑니다.

## 명령 입력 방법 (3가지 모두 동시 사용 가능)
1. **USB 시리얼 모니터**: Arduino IDE 시리얼 모니터, 115200 baud, 줄 끝 `Newline` (또는 `Both NL & CR`). "No line ending"이면 명령이 실행되지 않습니다.
2. **Wi-Fi 웹 페이지**: 브라우저에서 `http://<ESP32 IP>` 접속. 화살표, 램프, 남은 시간이 실시간으로 보이고 버튼으로 제어합니다.
3. **Wi-Fi 터미널**: Arduino IDE 시리얼 모니터는 USB 전용이라 Wi-Fi로는 붙지 않습니다. 대신 PuTTY(연결 유형 `Raw` 또는 `Telnet`)로 `<ESP32 IP>` 포트 `23`에 접속하면 시리얼 모니터와 똑같이 명령을 입력하고 상태를 볼 수 있습니다.

### Wi-Fi 연결
- 코드 상단 `WIFI_SSID` / `WIFI_PASS`에 공유기 정보를 넣으면 공유기에 연결하고, 할당된 IP를 시리얼 모니터에 출력합니다.
- 비워 두거나(`YOUR_SSID`) 15초 안에 연결하지 못하면 ESP32가 직접 AP를 만듭니다.
  PC Wi-Fi를 `TrafficLight-C3` (비밀번호 `12345678`)에 연결한 뒤 `http://192.168.4.1` 로 접속하세요.
- Wi-Fi 연결은 신호등 동작을 멈추지 않습니다. 전원을 켜면 바로 빨간불부터 시작합니다.

## Arduino IDE 설정
- 보드 매니저에서 **esp32 by Espressif** 설치 → 보드 `ESP32C3 Dev Module`
- `Tools > USB CDC On Boot` → **Enabled** (ESP32-C3 내장 USB로 시리얼 모니터를 쓸 때 필수)

## 배선 (중요)
ESP32-C3 GPIO는 **3.3V / 수십 mA**까지만 낼 수 있어서 신호등 램프를 직접 켤 수 없습니다.
신호등 전원(보통 12V 또는 5V 어댑터)은 그대로 쓰고, 빨간불/초록불 선을 **릴레이 모듈** 또는 **NPN 트랜지스터·MOSFET**으로 스위칭하세요.

| ESP32-C3 | 연결 |
|---|---|
| GPIO 4 | 빨간불 릴레이(또는 MOSFET 게이트) IN |
| GPIO 5 | 초록불 릴레이(또는 MOSFET 게이트) IN |
| GND | 릴레이 모듈 GND (MOSFET이면 신호등 전원 GND와 공통) |
| 5V / 3.3V | 릴레이 모듈 VCC (모듈 사양에 맞춰서) |

- 2채널 릴레이 모듈을 쓰는 경우: 신호등의 공통선(+)을 릴레이 COM에, 빨간불/초록불 선을 각 NO 단자에 연결합니다.
- 릴레이 모듈이 **LOW 입력에 동작**하는 제품이면 코드의 `ACTIVE_HIGH`를 `false`로 바꾸세요.
- GPIO 2, 8, 9는 부팅 관련 핀이라 피했습니다. 다른 핀을 쓰려면 `RED_PIN`, `GREEN_PIN`만 바꾸면 됩니다.
- 신호등 내부 배선(공통 +인지 공통 −인지, 사용 전압)은 제품마다 다르니 테스터기로 먼저 확인하세요.
